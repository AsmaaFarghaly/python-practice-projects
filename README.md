# python-practice-projects
Small programs I built while learning Python.

## Projects
- Guessing Game: the computer picks a random number and the player tries to guess it, with higher/lower hints
- Calculator: performs basic operations with input validation
- Timer: counts down or measures time for a given duration
- To-Do List: lets the user add, view, and remove tasks

## Concepts practiced
Functions, loops, conditionals, lists, user input, exception handling

## How to run
python guessing_game.py
python calculator.py
python timer.py
python todo_list.py
